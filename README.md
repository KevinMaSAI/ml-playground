# 机器学习闯关实验室

源码仓库：[KevinMaSAI/ml-playground](https://github.com/KevinMaSAI/ml-playground)

在线地址（GitHub Pages 发布完成后生效）：[打开机器学习闯关实验室](https://kevinmasai.github.io/ml-playground/)

十个可玩的机器学习实验，全部装在一个 `index.html` 中。中文暗色界面，Canvas 实时可视化，鼠标 / 触屏交互，自动保存通关进度。

**不用安装任何软件包，不用 npm、不用构建、不用后端。** 所有算法均用原生 JavaScript 实现，没有 CDN、远程字体、图片或模型请求。

## 本地打开

1. 下载 `index.html`，保留 `.html` 扩展名。
2. 双击，用现代版 Edge、Chrome、Firefox 或 Safari 打开。
3. 点“开始我的实验”，或自由进入任意关卡。

`README.md` 只是说明，不影响游戏运行。`index.html` 本身就是完整应用，不依赖任何相邻文件。没有 `fetch`、模块导入或跨域请求，因此 `file://` 也可以运行。

手机建议打开部署后的 HTTPS 链接。部分手机文件管理器会使用不能运行 JavaScript 的文档预览器；请使用真正的浏览器。

## 部署到 GitHub Pages

第一次使用 GitHub Pages，需要在仓库里选一次发布来源；应用本身不需要构建配置。

1. 新建一个 GitHub 仓库，例如 `ml-playground`。普通免费账号可使用公开仓库。
2. 在仓库首页选择 **Add file → Upload files**，上传 `index.html`，也可一并上传本说明。
3. 确认 `index.html` 位于仓库根目录，提交文件。不要把外层 `outputs` 文件夹整个套进去。
4. 进入 **Settings → Pages**。
5. 在 **Build and deployment → Source** 选择 **Deploy from a branch**。
6. 选择 **main** 分支和 **/(root)**，点击 **Save**。
7. 等待 Pages 完成发布，以设置页提供的实际链接为准。常见项目地址为 `https://你的用户名.github.io/ml-playground/`。
8. 把 HTTPS 链接发给别人，对方打开就能玩。后续更新只需上传替换 `index.html` 并提交。

部署流程依据 [GitHub 官方发布来源说明](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site) 与 [创建 Pages 网站说明](https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site)。不需要自行安装 Jekyll 或编写构建脚本。其他支持直接上传静态 HTML 的托管服务也适用。

已内置网页标题、description、Open Graph / Twitter 标题和描述，以及 data URI 内联 SVG favicon。分享平台是否生成卡片取决于平台是否抓取网页。为保持单文件且不写死部署域名，未设置依赖公网图片地址的 `og:image`，因此不保证所有平台都显示缩略图；普通页面标题和描述已配置。

## 基本规则

- 进入关卡 → 阅读讲解 → 动手操作 / 调参 → 训练 / 单步 → 达标通关。
- 每关首次通过得到 **100 XP**，十关共 **1000 XP**。重玩不重复计分。
- 所有关卡一直开放，可以顺序玩，也可以自由跳关。
- 控制台绿色框显示该关的明确通关条件，达到后自动点亮。
- 画布支持鼠标 / 触屏。拖动手柄、聚类中心；点击预测点、地形起点或决策树叶节点。相应参数也有滑块或下拉控件。
- 点击训练后可暂停；“单步”推进一次更新，K-means 则推进一次分配或中心更新。
- “重置本关”恢复同一份固定种子数据和初始模型，不删除通关记录。
- 顶部“游戏说明”随时可打开，含完整规则和可点击的关卡速览表。查看说明期间训练暂停推进，关闭后恢复之前的训练状态。

## 卡住时可以这样试

以下是可复现的入门路线，不需要先看完才开始玩。

1. **回归**：默认学习率 0.18，点击自动拟合。改到 1.4 可以观察发散，重置后重新试。
2. **分类**：点击训练。再暂停拖动边界，看看混淆矩阵中哪一格发生变化。
3. **正则化**：先比较 1 阶和无正则的 12 阶；再尝试 **3 阶、L2、λ=0.0001**。重点看橙色验证点，不要只看训练误差。
4. **下山**：默认 0.08 可收敛；较大的 0.30 在单谷里会振荡发散。调整后点“回到起点”。双谷的左右谷底等深，用不同起点观察收敛位置。
5. **聚类**：先拖动中心，再点单步两次，完整观察“分配 → 更新”。默认 K=3 可自动收敛。
6. **KNN**：先用 K=1 评估，再试 K=3 或 K=5。少量训练错标签会使过小的 K 更不稳定；很大的 K 又会过度平滑。
7. **决策树**：根节点按 `x=0` 分；再对左右叶节点分别按 `y=0` 分。每次分完会自动选一个仍不纯的叶节点，也可从下拉框选。森林对比按钮不会替你完成手工树目标。
8. **神经网络**：默认 2 层、每层 12 个 Tanh 神经元、学习率 0.18，开始训练。改变结构或激活函数会重新初始化；小网络或 Sigmoid 可能需要更多迭代。
9. **强化学习**：默认参数开始训练，观察橙色贪心路线。切换 SARSA 会清空 Q 表以重新比较。保留一定探索时，SARSA 通常更避开悬崖，但具体学习过程会有波动。
10. **综合挑战**：先评估 KNN / K=5，再比较树深度和线性模型。排行榜显示真实 CV 与测试结果。

## 算法与教学边界

- 回归与逻辑回归：手写梯度下降；逻辑回归使用交叉熵梯度，不用预设“正确答案”移动边界。
- 多项式：L2 用带部分主元的高斯消元求解正规方程；L1 用软阈值坐标下降近似求解。截距不惩罚。L1 的小 λ / 高阶设置可能在有限迭代内未完全收敛，界面有说明。无正则 L2 带极小的数值稳定项。
- 第三关的“最低值”仅指预设的 12 个阶数 × 7 个 L2 λ 候选网格，**不是所有可能模型的全局最优**。L1 可以参与挑战，只要验证误差达到同一阈值。
- 双谷使用 `(x²−1)²+y²`，两个局部谷底等深。它演示起点影响收敛位置，不演示两谷高低差异。
- K-means 实现最近中心分配、均值更新和空簇重定位。不同 K 都能收敛；“收敛”不等于自动找到了最合适的 K。
- KNN 用欧氏距离平方排序与奇数 K 多数投票，测试点不进入投票样本库。
- 决策树支持手工递归划分，手工最大深度 5。简易森林用 7 份自助采样数据、节点随机特征候选和多数票，最大深度 4。
- 神经网络只输入原始 x、y，不预先提供半径等答案特征。训练使用原生数组运算、全批量反向传播和普通梯度下降。自动训练每次刷新推进 8 轮，单步推进 1 轮。权重连接的颜色表示正负、粗细表示大小；节点橙环和逐层表格显示梯度。
- 强化学习是 8×6 确定性悬崖世界。移动奖励 −1，坠崖 −30，宝藏 +20。到宝藏 / 坠崖结束本回合，100 步会截断重开。终止转移不加未来估值。通关检测使用关闭探索的固定起点策略重复 10 次；确定性环境中的十次结果相同，**不代表探索中的所有路线都安全**。
- 综合挑战的三折按固定索引划分，三次分别在开发数据的 2/3 上训练、1/3 上验证；随后用全部开发数据训练，并在固定独立测试集上评分。测试集从不参与训练。反复观察测试分数调参仍可能对测试集过拟合，真实研究应另留最终保密测试集。
- 所有随机数据与初始化使用固定种子，重置可以公平比较参数。

## 存档和隐私

- localStorage 键名：`ml-playground-v1`。
- 仅保存通过的关卡编号与最多 12 条综合挑战记录，不上传任何数据。
- 排行榜是**当前浏览器本地榜**，不是多玩家联网榜。
- 不保存当前模型参数和未完成的训练过程。
- 隐私模式、禁用存储或损坏存档不会造成白屏；游戏回退到本次会话内存，页面会提示存储不可用。
- 移动本地文件、切换浏览器、切换网址，可能进入不同的存储空间。清除网站数据会清除记录。
